
📄 Resume Parsing and Scoring with Python
This project automates the process of extracting key information (emails, phone numbers, and skills) from resumes in PDF and DOCX formats, and ranks them based on predefined skill keywords using Python.

🔍 Features
📂 Reads resumes from a Google Drive directory

📥 Supports .pdf and .docx formats

🧠 Extracts:

Email addresses

Phone numbers (with Indian formats)

Skills based on custom keywords

📊 Assigns scores to resumes using weighted keyword matching

✅ Filters and highlights top-matching resumes

🚀 Technologies Used
Python

pdfplumber

docx2txt

pandas

Google Colab

✅ Output
Displays a DataFrame showing:

File name

Email

Phone

Skills matched

Resume score
